# 信息安全规范

## 账号与密码
- 密码长度不少于 12 位，须同时包含大小写字母、数字和符号。
- 密码每 90 天更换一次，不得与最近 5 次使用过的密码重复。
- 严禁与他人共享账号；离职当天由 IT 部门停用全部账号。

## 办公设备
- 公司电脑必须开启磁盘加密和自动锁屏，锁屏时间不超过 5 分钟。
- 未经 IT 部门批准，不得在公司电脑上安装未列入白名单的软件。
- 设备丢失须在发现后 2 小时内报告 IT 部门，由 IT 远程擦除数据。

## 数据管理
- 客户资料、合同、财务数据属于机密级，禁止通过个人邮箱、个人网盘和即时通讯软件外发。
- 机密级文件须加密存放，传输须使用公司指定的加密通道。
- 离职员工须在最后工作日前交接全部工作资料，不得带走任何公司数据。

## 事件报告
- 发现疑似信息泄露、钓鱼邮件或账号异常，须立即报告 IT 部门，最迟不得超过 1 小时。
- 隐瞒不报的，按严重违纪处理。
